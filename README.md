# 🎬 Movie Recommendation System (Movie Finder)

A personalized **movie recommendation system** that helps users discover movies based on their preferences using a combination of **collaborative filtering** and **content-based filtering** techniques.

---

## 🎯 Objective

- Recommend movies tailored to user interests
- Enhance discovery based on genres, keywords, or viewing history
- Provide a user-friendly interface for fast suggestions
